# Random Cases and Raw Data

`models/G1` through `models/G8` each contain 30 independently generated cases,
named `case1` through `case30`. Every case is a connected network of
deterministic one-clock RTAs; component files are named `P1.json`, `P2.json`,
and so on.

The groups vary the number of components, global alphabet size, locations,
transitions, and clock-bound range. Values within a group were sampled per
component; no case was generated by first fixing a group-wide transition or
clock-bound total.

`results/G<group>_<algorithm>.csv` contains the canonical 30 raw rows for one
group and one algorithm. There are 24 such files. Algorithms are encoded in
the CSV as `comp` (CL), `mct` (TOT), and `ttt` (TCT).

Random runs used a 300-second timeout and a 16-GiB address-space limit. A
`TIMEOUT` row retains the latest available query counters. `timeMs` is empty
when the run did not finish. The additional files under `statistics/` are
derived summaries; `averageKi` is the direct arithmetic mean of component
`K_i` values.
